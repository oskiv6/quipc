# Contributing to Quip

Thank you for your interest in Quip! 

## Current Status: Solo Development & Contributions Paused

Right now, Quip is in an early, rapid exploration phase where the core goals, language semantics, syntax, and memory management architecture are still evolving and stabilizing. 

Because the vision and internal structure of the compiler change frequently during this phase, **I am not accepting external code contributions or Pull Requests at this time.** Managing external PRs right now would slow down core architectural decisions and lead to duplicated or conflicting work.

### How You Can Still Help Right Now

While code contributions are currently paused, you are more than welcome to:
* **Test Nightly Releases**: Try out pre-built `quipc` binaries.
* **Report Bugs**: Open an issue on GitHub if you encounter compiler crashes (`segfaults` inside `quipc`), incorrect type analysis, or misleading contextual error messages.
